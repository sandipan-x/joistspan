# JoistSpan

Max floor joist span by lumber size, species, spacing and load, with deflection check.

## Features
- Species + grade + spacing + live/dead load selectors
- Deflection check (L/360) with pass/fail verdict
- Sistering / mid-span beam recommendation when it fails
